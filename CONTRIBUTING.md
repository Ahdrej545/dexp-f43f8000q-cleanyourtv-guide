# Участие в проекте

Спасибо за желание помочь владельцам DEXP F43F8000Q-G и других похожих Android TV.

## Перед отправкой изменений

- Уточни модель телевизора, версию Android и номер сборки прошивки, если он важен для проблемы.
- Указывай, что проверено на реальном устройстве, а что является предположением.
- Не добавляй APK CleanYourTV, дампы с личными данными, ADB-ключи, IP-адреса домашней сети, MAC-адреса, серийные номера или Wi-Fi-имена.
- Не добавляй команды, отключающие или удаляющие системные пакеты без проверки конкретной модели и доказанного способа отката.
- Не называй `am force-stop` «очисткой RAM»: это принудительно останавливает процессы приложений и может не давать устойчивого прироста свободной памяти.

## Проверки

Перед Pull Request запусти:

```bash
python3 scripts/validate_repo.py
bash -n scripts/tv-menu.sh
```

Изменения PowerShell-скриптов нужно проверять в Windows PowerShell. Виртуальная проверка на Linux не доказывает совместимость с каждой версией Android TV.

## Issues и скриншоты

Перед публикацией скриншота замаскируй Wi-Fi-имя, адреса, учётные записи и прочие личные сведения. При описании ошибки достаточно модели, версии Android, последовательности шагов и обезличенного сообщения об ошибке.
