# Как откатить изменения

Сначала попробуй штатные настройки и физический пульт. Команды ниже предназначены только для устройства, к которому у тебя есть законный доступ, и предполагают подключённый ADB.

## 1. Вернуть штатный HOME-лаунчер

Сначала попробуй включить пакет штатного лаунчера, если его ранее отключали:

```powershell
adb shell pm enable --user 0 com.yandex.tv.home
```

Затем назначь штатный компонент HOME:

```powershell
adb shell cmd package set-home-activity --user 0 com.yandex.tv.home/.HomeActivity
```

Проверь, что пакет и компонент существуют в твоей прошивке. Если команды сообщают, что компонент не найден, не перебирай случайные имена: изучи `adb shell dumpsys package com.yandex.tv.home` и настройки приложений телевизора.

## 2. Вернуться к CleanYourTV

Если пакет CleanYourTV установлен и исправен:

```powershell
adb shell cmd package set-home-activity --user 0 com.gathin.tvhome/.MainActivity
```

## 3. Удалить CleanYourTV

Сначала назначь и проверь штатный лаунчер, а затем при необходимости удали только пользовательский пакет:

```powershell
adb uninstall com.gathin.tvhome
```

Не выполняй удаление, если штатный лаунчер не запускается или ты не уверен в доступности настроек.

## 4. Сбросить визуальные изменения

Если проблема только во внешнем виде, попробуй выбрать другую тему и обои в настройках CleanYourTV. Это предпочтительнее удаления приложения.

## Важно

- Не очищай данные всех системных приложений.
- Не отключай системный лаунчер ради чистоты списка приложений, пока не проверены запасной путь восстановления и физический доступ к меню.
- Команда `pm enable` помогает только если пакет был отключён и ещё присутствует в системе. Она не восстанавливает удалённый системный пакет и не чинит прошивку.
