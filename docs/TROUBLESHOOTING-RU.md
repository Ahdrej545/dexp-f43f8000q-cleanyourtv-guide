# Устранение неполадок

## `adb connect` не подключается

1. Убедись, что компьютер и телевизор в одной локальной сети.
2. Проверь IP телевизора в сетевых настройках — адрес роутера и адрес телевизора не одно и то же.
3. Проверь, включена ли отладка по сети и разрешено ли подключение.
4. Попробуй снова подключиться: `adb connect <IP-ТЕЛЕВИЗОРА>:5555`.
5. После завершения настройки отключи ADB в параметрах разработчика.

Не публикуй в Issues полный диагностический лог, если в нём есть адреса, серийные номера или личные данные.

## После перезагрузки снова открывается штатный лаунчер

Проверь назначенный HOME-компонент:

```powershell
adb shell cmd package resolve-activity --brief -a android.intent.action.MAIN -c android.intent.category.HOME
```

Если HOME — не CleanYourTV, а пакет и компонент установлены, повтори команду из раздела «Быстрый запуск через ADB» в README. Если CleanYourTV уже указан как HOME, но штатный экран всё равно выходит на передний план, не отключай системные пакеты сразу: сначала проверь доступность настроек, физической кнопки Home и возможность возврата к штатному лаунчеру.

## Компонент не найден

Проверь установленные пакеты:

```powershell
adb shell pm list packages | findstr /i "gathin yandex cvte"
```

И сведения о пакете:

```powershell
adb shell dumpsys package com.gathin.tvhome
```

Имя компонента может измениться в другой версии приложения. Не используй команды из руководства вслепую на другом лаунчере.

## Специальные возможности не переживают перезагрузку

Некоторые прошивки Android TV сбрасывают пользовательские настройки специальных возможностей или не подключают сервис ожидаемым образом. В этом проекте включение `HomeKeyService` не считается обязательным шагом базовой установки. Сначала проверь назначение HOME и работу пульта без принудительного изменения secure settings.

## Телевизор выглядит медленнее после изменений

Верни прежнюю тему, отключи тяжёлые анимации, проверь свободное хранилище и перезагрузи телевизор. Не используй универсальные команды для отключения системных приложений: их последствия зависят от прошивки.
