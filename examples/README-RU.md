# Примеры конфигурации CleanYourTV

Эти JSON-файлы — примеры настроек интерфейса, а не прошивка и не APK.

- [config-neon-safe.json](config-neon-safe.json) — стартовая тема без скрытых приложений.
- [config-neon-hidden-3.json](config-neon-hidden-3.json) — вариант, основанный на конфигурации владельца с тремя скрытыми пакетами.
- [config-neon-device-reference.json](config-neon-device-reference.json) — вариант, основанный на конфигурации владельца с пятью скрытыми пакетами.

## Важно перед импортом

1. Проверь, поддерживает ли твоя версия CleanYourTV импорт этого формата и все перечисленные ключи.
2. Сначала экспортируй собственные настройки, если твоя версия это поддерживает.
3. Для первого запуска используй безопасный пример без скрытых приложений.
4. Ключ `hidden_apps` предназначен для скрытия ярлыков в лаунчере, если это поддерживается твоей версией; это не отключение и не удаление пакетов.
5. Варианты со скрытыми пакетами привязаны к одной конфигурации DEXP F43F8000Q-G. В других телевизорах эти компоненты могут быть полезны или отсутствовать, поэтому не импортируй их вслепую.

Указанные package ID могут отсутствовать на других моделях, прошивках или версиях приложений.
