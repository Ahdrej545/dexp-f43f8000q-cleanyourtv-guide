# Примеры конфигурации CleanYourTV

Эти JSON-файлы — примеры настроек интерфейса, а не прошивка и не APK.

- config-neon-safe.json — рекомендуемая стартовая тема: тёмный фон, 6 колонок, короткий док, уменьшенные анимации и без скрытых приложений.
- config-neon-device-reference.json — конфигурация, похожая на использованную владельцем одного DEXP F43F8000Q-G. В ней список hidden_apps скрывает дополнительные значки из интерфейса лаунчера.

## Важно перед импортом

1. Проверь, поддерживает ли твоя версия CleanYourTV импорт этого формата и все перечисленные ключи.
2. Сначала экспортируй собственные настройки, если твоя версия это поддерживает.
3. Для первого запуска используй безопасный пример без скрытых приложений.
4. Ключ hidden_apps скрывает приложения только в лаунчере (если именно так работает твоя сборка); он не должен использоваться как замена отключению или удалению системных пакетов. Убедись, что понимаешь, какие ярлыки скрываются.
5. В устройственно-специфичном примере скрываются в том числе пакеты CVTE и ADB AppControl. Другие модели и версии прошивки могут нуждаться в этих ярлыках — поэтому этот файл не предназначен для слепого импорта.

Указанные package ID привязаны к конкретному набору установленных приложений и могут отсутствовать на других телевизорах.
