# Примеры конфигурации CleanYourTV

Эти JSON-файлы — примеры настроек интерфейса, а не прошивка, APK или полноценный пакет темы.

- [config-neon-safe.json](config-neon-safe.json) — стартовая тема без скрытых приложений и без обязательного пользовательского файла обоев.
- [config-neon-hidden-3.json](config-neon-hidden-3.json) — вариант на основе конфигурации владельца с тремя скрытыми ярлыками.
- [config-neon-device-reference.json](config-neon-device-reference.json) — вариант, основанный на конфигурации владельца с пятью скрытыми ярлыками.

## Перед импортом

1. Проверь, поддерживает ли установленная версия CleanYourTV импорт этого формата и все перечисленные ключи.
2. Сначала экспортируй собственные настройки, если твоя версия это поддерживает.
3. Для первого запуска используй безопасный пример без скрытых приложений.
4. Ключ `hidden_apps` скрывает ярлыки только в лаунчере; он не отключает и не удаляет пакеты.
5. В примерах с `hidden_apps` указаны пакеты одной конфигурации DEXP F43F8000Q-G. В других телевизорах эти компоненты могут быть полезны или отсутствовать — не импортируй такой список вслепую.
6. Во всех JSON-примерах параметр `wallpaper` выключен. Чтобы использовать свои обои, сначала подготовь файл `wallpaper.jpg` или коллекцию обоев в формате, поддерживаемом твоей версией CleanYourTV, затем включи параметр. Векторный фон находится в [assets/neon-waves.svg](../assets/neon-waves.svg); при необходимости экспортируй его в PNG/JPG.

Package ID привязаны к конкретному набору приложений и могут отличаться даже у телевизоров одной линейки.
