Практическое руководство по настройке домашнего экрана CleanYourTV на телевизоре **DEXP F43F8000Q-G с Android 9**. Здесь собраны проверенный на одном устройстве сценарий, скрипты ADB для Windows/Linux, примеры конфигурации, восстановление и правила безопасности.

> **Проверено на одном экземпляре:** DEXP F43F8000Q-G, Android 9.0, пакет CleanYourTV `com.gathin.tvhome`. Ревизии платы и прошивки могут отличаться. Это руководство не является прошивкой и не гарантирует совместимость со всеми вариантами модели.

## Перед началом

1. Подключи телевизор и компьютер к одной доверенной домашней сети.
2. Установи Android Platform Tools (`adb`).
3. Убедись, что у тебя есть физический доступ к телевизору и пульту.
4. До изменений сохрани список приложений и текущие настройки. Не полагайся только на сетевой ADB как на единственный способ восстановления.
5. Не отключай системные приложения CVTE/HiSilicon и не меняй системные разрешения «на всякий случай».

CleanYourTV — отдельный проект. Этот репозиторий содержит руководство, примеры и пользовательские скрипты, но **не распространяет APK или исходный код CleanYourTV**. См. [оригинальный проект](https://github.com/Gathin23/cleanyourtv) и соблюдай его лицензию и инструкции.

## Интеграция с мобильным приложением

Для настройки с Android-телефона существует [Clean Your TV App](https://github.com/udhaykumarbala/cleanyourtv-app). Оно может подключаться к телевизору через ADB, показывать план действий и поддерживает сценарии восстановления. Для этой модели отдельный профиль в списках мобильного приложения пока не найден, поэтому не запускай очистку вслепую.

Пошаговое объяснение, как безопасно проверить приложение и предложить DEXP-профиль сообществу: [Интеграция с Clean Your TV App](docs/APP-INTEGRATION-RU.md).

## Быстрый запуск через ADB

Открой PowerShell и введи IP-адрес телевизора, показанный в сетевых настройках. В примерах намеренно не зашит адрес конкретного телевизора.

```powershell
$tvIp = Read-Host "IP-адрес телевизора"
adb connect "$($tvIp):5555"
adb shell cmd package resolve-activity --brief -a android.intent.action.MAIN -c android.intent.category.HOME
```

Если CleanYourTV установлен и компонент доступен, назначить его домашним экраном можно так:

```powershell
adb shell cmd package set-home-activity --user 0 com.gathin.tvhome/.MainActivity
```

Проверь результат:

```powershell
adb shell cmd package resolve-activity --brief -a android.intent.action.MAIN -c android.intent.category.HOME
adb shell dumpsys activity activities | findstr /i "mResumedActivity"
```

Ожидаемый компонент HOME: `com.gathin.tvhome/.MainActivity`. Активным экраном временно могут быть настройки или другое приложение — само по себе это не ошибка.

Если пакет или компонент отличается, остановись и проверь версию приложения. Не подставляй команды для другой модели телевизора.

## Оформление интерфейса

Названия разделов могут различаться между версиями CleanYourTV. Если они доступны в установленной версии:

1. Выбери тёмную тему.
2. Используй холодные оттенки — синий, фиолетовый и бирюзовый; на слабом оборудовании избегай слишком яркого свечения.
3. Выбери широкоформатные обои. Для Full HD-панели лучше использовать изображение 1920×1080 или выше, для 4K — 3840×2160.
4. Оставь на главном экране только нужные приложения и выбери удобное число строк и столбцов.
5. Если анимации замедляют интерфейс, отключи лишние эффекты.
6. После изменений проверь Home, голосовой поиск, HDMI/источники и основные приложения.

Не устанавливай в качестве обоев изображение-инструкцию или скриншот интерфейса — используй чистый фон.

## Скрипты управления

В папке [scripts](scripts/) доступны:

- [tv-menu.ps1](scripts/tv-menu.ps1) — интерактивное меню для Windows PowerShell.
- [tv-menu.sh](scripts/tv-menu.sh) — интерактивное меню для Linux.
- [inspect-tv.ps1](scripts/inspect-tv.ps1) — диагностический скрипт только для чтения.

Меню может подключаться через ADB, назначать CleanYourTV домашним экраном, показывать сведения о памяти, сохранять скриншот, выводить список отключённых пакетов и пробовать копировать каталог файлов лаунчера. При запуске меню запрашивает IP-адрес; пользовательский адрес в репозитории не хранится.

Пункт закрытия приложений использует `am force-stop` — это **не очистка оперативной памяти**, а принудительное закрытие выбранных приложений. Перед действием требуется подтверждение; штатный лаунчер Яндекса в список не включён. Остановленные приложения могут запуститься снова, а поведение зависит от прошивки.

Запуск в Windows из корня проекта:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\tv-menu.ps1
```

Запуск в Linux:

```bash
chmod +x scripts/tv-menu.sh
./scripts/tv-menu.sh
```

Для диагностики в Windows:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\inspect-tv.ps1
```

Скрипты не отключают и не удаляют пакеты. Перезагрузка — отдельный пункт с подтверждением. До использования просмотри исходный код и убедись, что понимаешь команды.

## Примеры конфигурации

В папке [examples](examples/) находятся JSON-примеры:

- [config-neon-safe.json](examples/config-neon-safe.json) — тёмный стиль без скрытых ярлыков.
- [config-neon-hidden-3.json](examples/config-neon-hidden-3.json) — вариант с тремя скрываемыми ярлыками из личной конфигурации.
- [config-neon-device-reference.json](examples/config-neon-device-reference.json) — вариант с пятью скрываемыми ярлыками, ориентированный на один DEXP.
- [Пояснения и предупреждения](examples/README-RU.md).

Сначала используй безопасный пример. Формат и значения должны поддерживаться именно твоей версией CleanYourTV; не импортируй конфигурацию вслепую. `hidden_apps` скрывает ярлыки в лаунчере, а не отключает пакеты. В устройственно-специфичном примере есть компоненты CVTE и ADB AppControl; на другом устройстве они могут быть нужны или отсутствовать.

## Диагностика

`scripts/inspect-tv.ps1` подключается к указанному IP и читает сведения о модели, версии Android, HOME-компоненте, активном экране и настройках специальных возможностей. Он не отключает пакеты и не меняет настройки телевизора.

Если ADB выдаёт ошибку, см. [устранение неполадок](docs/TROUBLESHOOTING-RU.md).

## Безопасность

- Не публикуй IP-адрес телевизора, MAC-адрес, серийный номер, ADB-ключи, дампы настроек с личными данными или личные резервные копии.
- Не оставляй сетевой ADB включённым, когда он не нужен. Порт 5555 может предоставить shell-доступ устройствам в доступной сети, если прошивка принимает подключения.
- Не отключай `com.yandex.tv.home` или другие системные пакеты, пока не проверены возврат к штатному лаунчеру и доступ к настройкам. Компоненты зависят от прошивки.
- Не прошивай телевизор по этой инструкции. Здесь не описана безопасная процедура восстановления firmware.
- Перед изменением настроек изучи [инструкцию по откату](docs/ROLLBACK-RU.md).

## Проверки и ограничения

Репозиторий включает автоматическую проверку JSON, SVG, локальных Markdown-ссылок и синтаксиса Bash на Ubuntu, а также разбор синтаксиса PowerShell на Windows runner. CI не выполняет скрипты и не подключается к телевизору; фактическая совместимость проверена только в описанном опыте автора.

Это пользовательская заметка по одному успешно настроенному устройству, а не официальная документация DEXP, CVTE, Яндекса или разработчика CleanYourTV. Уточнения по точной прошивке, фото меню без личных данных и проверенные исправления приветствуются в Issues/Pull Requests.
