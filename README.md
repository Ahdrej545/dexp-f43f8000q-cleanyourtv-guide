# DEXP F43F8000Q-G + CleanYourTV

Практическое руководство по настройке домашнего экрана CleanYourTV на телевизоре **DEXP F43F8000Q-G с Android 9**. Проект собирает в одном месте опыт настройки, проверочные команды ADB, заметки о восстановлении и правила безопасности.

> **Проверено на одном экземпляре:** DEXP F43F8000Q-G, Android 9.0, пакет CleanYourTV `com.gathin.tvhome`. Разные ревизии платы, прошивки и партии телевизора могут вести себя иначе. Это не универсальная прошивка и не гарантия совместимости.

## Что получилось

- CleanYourTV установлен и назначен HOME-лаунчером.
- Главный экран оформлен в тёмном техно-стиле с неоновыми акцентами и коротким рядом приложений.
- После перезагрузки и проверки кнопки Home на испытанном телевизоре CleanYourTV открывался корректно.
- Владелец отметил более плавную работу интерфейса. Это субъективный результат конкретной конфигурации, а не гарантированный прирост производительности для каждого устройства.

## Перед началом

1. Подключи телевизор и компьютер к одной доверенной домашней сети.
2. Установи Android Platform Tools (`adb`) на компьютер.
3. Убедись, что у тебя есть физический доступ к телевизору и пульту.
4. До экспериментов сохрани список приложений и текущие настройки. Не полагайся только на сетевой ADB как на единственный способ восстановления.
5. Не отключай системные приложения CVTE/HiSilicon и не меняй системные разрешения «на всякий случай».

CleanYourTV — отдельный проект. Этот репозиторий содержит руководство и диагностический скрипт, но **не распространяет APK или исходный код CleanYourTV**. См. [оригинальный проект](https://github.com/Gathin23/cleanyourtv) и соблюдай его лицензию и инструкции.

## Быстрый запуск через ADB

Открой PowerShell и подставь IP-адрес телевизора, который показан в сетевых настройках. Не используй адрес из чужого примера.

```powershell
adb connect <IP-АДРЕС-ТЕЛЕВИЗОРА>:5555
adb shell cmd package resolve-activity --brief -a android.intent.action.MAIN -c android.intent.category.HOME
```

Если CleanYourTV установлен и его компонент доступен, назначить его домашним экраном можно так:

```powershell
adb shell cmd package set-home-activity --user 0 com.gathin.tvhome/.MainActivity
```

Проверь результат:

```powershell
adb shell cmd package resolve-activity --brief -a android.intent.action.MAIN -c android.intent.category.HOME
adb shell dumpsys activity activities | findstr /i "mResumedActivity"
```

Ожидаемый компонент HOME: `com.gathin.tvhome/.MainActivity`. Активное приложение может временно быть настройками или другим открытым приложением — это само по себе не ошибка.

Если пакет или компонент отличается, остановись и проверь версию приложения. Не подставляй команды для другой модели телевизора.

## Оформление интерфейса

Названия разделов могут различаться между версиями CleanYourTV. Если они доступны в установленной версии:

1. Открой настройки CleanYourTV и выбери тёмную тему.
2. Используй холодные оттенки — синий, фиолетовый и бирюзовый; избегай слишком яркого свечения на слабом оборудовании.
3. Установи широкоформатные обои высокого разрешения. Для UHD-экрана обычно подходит 3840×2160; для другого разрешения можно использовать исходное разрешение панели.
4. Оставь на главном экране только нужные приложения и выбери удобное число строк и столбцов.
5. Если анимации делают интерфейс медленнее, отключи лишние эффекты.
6. Перезагрузи телевизор и проверь Home, голосовой поиск, HDMI/источники и основные приложения.

Не устанавливай в качестве обоев изображения-инструкции или скриншоты интерфейса: для этого подходят отдельные чистые фоновые изображения.

## Диагностика

В папке [`scripts`](scripts/) лежит `inspect-tv.ps1`. Скрипт подключается к указанному IP и читает сведения о модели, версии Android, HOME-компоненте, текущем активном экране и настройках специальных возможностей. Он не отключает пакеты и не меняет настройки телевизора.

Запуск из PowerShell в папке проекта:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\scripts\inspect-tv.ps1
```

Если PowerShell или ADB выдаёт ошибку, см. [диагностику](docs/TROUBLESHOOTING-RU.md).

## Безопасность

- Не публикуй IP-адрес телевизора, MAC-адрес, серийный номер, дампы настроек с личными данными или файлы резервной копии.
- Не оставляй сетевой ADB включённым, когда он не нужен. Порт 5555 позволяет устройствам в доступной сети обращаться к ADB, если телевизор принимает соединения.
- Не отключай `com.yandex.tv.home` или другие системные пакеты, пока не проверены возврат к штатному лаунчеру и доступ к настройкам. У разных сборок компонент может отличаться.
- Не прошивай телевизор по этой инструкции. Здесь не описана безопасная процедура восстановления прошивки.
- Перед изменением настроек изучи [инструкцию по откату](docs/ROLLBACK-RU.md).
